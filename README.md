# YDITS for YQL

## 概要

yumin地震観測所 (YQL) が提供する防災 Discord BOT です。  
YDITS が yumin地震観測所 用に制作・ライセンス提供しています。

## 利用方法

### モジュールをインストール

```bash
pip install -r requirements.txt
```

### 実行

```bash
python -m ydits_yql
```

## ライセンス

このプロジェクトはライセンスされません。

このプロジェクトは、YDITS が開発し、yumin地震観測所 が提供しています。

**yumin地震観測所 (YQL)** は **yumin** が運営する防災団体です。

**YDITS** は **よね/Yone** が運営する防災サービスです。
